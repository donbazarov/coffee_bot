# НЕФТЬ · Coffee Quality

Веб-сервис для сети кофеен НЕФТЬ: качество напитков, график смен, команда и
истории гостей. Проект вырос из Telegram-бота — от него осталась только
интеграция с Telegram для входа сотрудников, а сам бот-код удалён.

Продакшен: **https://neftcoffee.shop** (бот входа — `@NeftCoffeeBot`).

## Возможности

- **Качество напитков** — дашборд с фильтром по периоду: количество и средний
  балл оценок, недельная динамика, рейтинг бариста и последние оценки.
- **Команда** — сотрудники и роли (бариста, старший, наставник), заявки гостей
  на доступ и выдача прав.
- **График смен** — нативный календарь: просмотр, правка (замены и расписание),
  снимок графика, история изменений, шаблоны смен и экспорт в iCalendar.
- **Истории гостей** — публичная страница `/stories` с модерацией в личном
  кабинете наставника.
- **Вход через Telegram** — по ссылке на бота; работает без VPN, в отличие от
  штатного виджета.
- **Интерфейс и персонализация** — светлая/тёмная/системная тема, выбор
  акцентного цвета, отображаемое имя и фото профиля, мобильное меню-drawer.

## Интерфейс и персонализация

- **Оформление.** Тема (светлая / тёмная / как в системе) и акцентный цвет
  настраиваются в личном кабинете и хранятся в аккаунте (`web_user_preferences`),
  поэтому подхватываются на любом устройстве. Акцент по умолчанию — мягкий
  коралл `#F47369`; он же красит логотип и активные элементы. Тема применяется
  до первой отрисовки (`static/theme-boot.js`), так что нет «вспышки».
- **Аккаунт.** Отображаемое имя (видно команде в графике и интерфейсе) и фото
  профиля. Фото из Telegram подтягивается один раз при первом входе, его можно
  загрузить вручную или сбросить.
- **Разделы.** «Личный кабинет» (профиль, оформление, модули) отделён от
  «Панели управления» (шаблоны смен, каналы публикаций, модерация историй —
  только старший/наставник). На телефоне навигация — выдвижная панель (drawer).
- **Типографика** — Montserrat (заголовки и интерфейс) и DM Mono (числа, метки).
- **Мгновенный запуск.** Приложение можно сохранить на домашний экран телефона.
  Оболочка (HTML, стили, скрипты, шрифты и иконки) лежит в кеше устройства —
  `static/sw.js`, Service Worker — поэтому первый экран рисуется сразу,
  не дожидаясь сети, а данные подгружаются в фоне. Ключ кеша — отпечаток
  статики, так что после деплоя старая версия выбрасывается сама.
  Запросы к `/api/`, `/auth/`, `/avatars/` и любые не-GET идут всегда в сеть:
  данные не устаревают. Сам воркер отдаётся из корня (`GET /sw.js`) и не кешируется.

## Стек

FastAPI + Uvicorn, Jinja2, SQLAlchemy (доступ к данным — сырым SQL), SQLite,
Pillow (рендер снимка графика). Python 3.10+.

## Быстрый старт

```bash
python -m venv venv
venv\Scripts\activate            # Windows
# source venv/bin/activate       # Linux/macOS
pip install -r requirements.txt
copy .env.example .env           # Windows;  cp .env.example .env  — Linux/macOS
```

Заполните `.env` (минимум `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`,
`WEB_SESSION_SECRET`) и запустите:

```bash
python run.py
```

Сайт откроется на `http://127.0.0.1:8001` (адрес и порт задают `WEB_HOST` и
`WEB_PORT`). Для локального входа через полный сценарий нужен публичный
HTTPS-callback — см. `TELEGRAM_AUTH_CALLBACK_URL` ниже.

## Переменные окружения

Все настройки и секреты лежат в одном файле `.env` в корне (в git не попадает).
Значения из `.env` имеют приоритет над переменными окружения.

| Переменная | Назначение |
|---|---|
| `WEB_HOST` / `WEB_PORT` | адрес и порт приложения (по умолчанию `127.0.0.1:8001`) |
| `WEB_TIMEZONE` | часовой пояс графика и экспорта (`Europe/Moscow`) |
| `WEB_SESSION_SECRET` | подпись сессионных cookie (`openssl rand -hex 32`) |
| `WEB_COOKIE_SECURE` | `1` — cookie только по HTTPS (обязательно в проде) |
| `TELEGRAM_BOT_TOKEN` | токен бота; нужен для входа через Telegram |
| `TELEGRAM_BOT_USERNAME` | имя бота без `@` (пока не задано — вход отключён) |
| `TELEGRAM_AUTH_CALLBACK_URL` | публичный HTTPS-адрес `/auth/telegram/callback` |
| `DATABASE_URL` | путь к SQLite-базе (по умолчанию `coffee_quality.db` в корне) |
| `NEFT_DATA_DIR` | каталог историй гостей (по умолчанию `data/stories`) |
| `NEFT_SCHEDULE_SNAPSHOTS_DIR` | каталог снимков графика (`data/schedule_snapshots`) |
| `NEFT_AVATARS_DIR` | каталог аватаров сотрудников (по умолчанию `data/avatars`) |

Веб-слой намеренно работает с базой **сырым SQL** (`text()` и `engine.begin()`),
а не через ORM: ORM-модели в `bot/database/models.py` нужны только как источник
схемы при создании пустой базы.

## База данных

SQLite. На старте приложение само создаёт недостающие таблицы и прогоняет
идемпотентные миграции.

- **Данные НЕФТЬ**: `users` (сотрудники и роли), `drink_reviews` (оценки),
  `shift_types` и `schedule` (типы смен и график).
- **Сервисные таблицы веб-слоя**: `web_user_preferences`, `web_shift_change_log`,
  `web_shift_templates`, `web_app_settings`, `web_login_requests`,
  `web_shift_swap_requests`, `web_schema_migrations`.
- **Персонализация**: в `users` — `display_name` и `avatar_rev`, в
  `web_user_preferences` — `theme` и `accent`. Новые колонки докатываются
  идемпотентно на старте, на пустой базе не нужны.

В старых базах могут остаться неиспользуемые таблицы прежнего бота
(`checklist_*`, `secret_santa_2026`) — они больше не нужны, но и не мешают.

## Вход через Telegram

Основной вход — по ссылке на бота (виджет `telegram.org` в России блокируется):

1. `/auth/telegram/start` создаёт одноразовый токен и уводит в `t.me/<бот>?start=<токен>`;
2. сотрудник жмёт **Start** в приложении Telegram;
3. `bot/web/telegram_login_bot.py` подтверждает заявку;
4. страница `/auth/telegram/wait` опрашивает статус и получает сессию.

Заявки живут 10 минут и хранятся в `web_login_requests`. Новые аккаунты попадают
в раздел **Команда** как «Ожидает доступа» — роль выдаёт старший или наставник.

## Деплой

Инструкция по серверу (Docker Compose и systemd, nginx, HTTPS, бэкапы,
